## Two that need attention

- **libgomp / libquadmath** are GPL-3.0 and may be shipped with
  proprietary software only under the *GCC Runtime Library Exception*.
  That exception holds as long as compilation used no intermediate
  representation beyond what is GPL-compatible; ordinary GCC compilation
  qualifies. Re-check it if the toolchain changes or anything unusual
  beyond LTO is done.
- **The four CUDA libraries** are shipped under the redistributable
  clause of the NVIDIA EULA, only alongside this software.

## Which artifact contains what

- `bin/*` (serverpack): statically links Boost, OpenSSL, hnswlib,
  tree-sitter and its grammars, and libcurl. The inference code is not in
  these executables; it is in the backend pack.
- `bin/libcage-backend-*.so` (each backend pack): ik_llama.cpp (with its
  ggml / llama.cpp ancestry), vendored/safetensors and, as built by
  default, sd.cpp, trellis.cpp, audio.cpp and kimodo.cpp with what they
  vendor. Every backend pack carries exactly these licences in its own
  `licenses/`.
- Apache-2.0 components CAGE modified (audio.cpp, kimodo.cpp,
  vendored/safetensors): the files changed are listed in
  `licenses/<name>-MODIFICATIONS.txt` (section 4(b)), computed from git
  when the notices are generated; NOTICE files are in
  `licenses/<name>-NOTICE.txt` (section 4(d)).
