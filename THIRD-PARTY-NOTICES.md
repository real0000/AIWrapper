## Two that need attention

- **libgomp / libquadmath** are GPL-3.0 and may be shipped with
  proprietary software only under the *GCC Runtime Library Exception*.
  That exception holds as long as compilation used no intermediate
  representation beyond what is GPL-compatible; ordinary GCC compilation
  qualifies. Re-check it if the toolchain changes or anything unusual
  beyond LTO is done.
- **The three CUDA libraries** are shipped under the redistributable
  clause of the NVIDIA EULA, only alongside this software.

## Which artifact contains what

- `bin/*`: statically links ik_llama.cpp (with its ggml / llama.cpp
  ancestry), Boost, OpenSSL, hnswlib, tree-sitter and its grammars, and
  libcurl.
- `share/cage/convert_hf_to_gguf.py`, `share/cage/gguf-py/`: taken from
  ik_llama.cpp and distributed as **source** (MIT).

## Not distributed with this product

The following are installed by the user onto their own machine. CAGE does
not redistribute them and their licences are the user's to comply with:

- The Python packages `setup-workers.sh` installs with pip, and the
  upstream repositories it clones (InstantMesh, TRELLIS, Hunyuan3D-2).
  Some carry copyleft or non-commercial terms — see
  doc/server/server/workers.md. TRELLIS's AGPL/GPL dependencies
  (pymeshfix / igraph / plyfile) were changed to lazy imports by
  `patch_trellis_licence.py`, so the default path never installs them.
- **Model weights.** This product contains none, and
  `config.example.xml` holds only placeholder paths. Several common
  weights carry commercial restrictions (non-commercial, revenue
  thresholds, user-count thresholds, territorial exclusions) — see
  doc/server/server/models.md.
