Changes
-------

1. Include paths rewritten.
     "vllm/model_executor/model_loader/<name>.h"  ->  "cage_safetensors/<name>.h"
     "vllm/support/platform_compat.h"             ->  "cage_safetensors/platform_compat.h"
   The upstream layout nests these under a model_executor/model_loader tree that
   does not exist here; flattening them keeps the vendored copy self-contained.

2. Files relocated.
   Upstream keeps headers under include/vllm/... and sources under src/vllm/...;
   here they are include/cage_safetensors/ and src/. platform_compat.h lives
   under src/vllm/support/ upstream and is a header, so it moved to include/.

Not changed
-----------

  * The C++ namespace is still `vllm` / `vllm::detail` / `vllm::support`.
    Renaming it would make every future re-sync a manual diff, and the symbols
    are internal to this static library anyway.
  * No functional edits. If that ever changes, the change must be listed above
    together with the reason.
